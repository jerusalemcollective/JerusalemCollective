# JLM Collective advanced SEO content strategy

## Goal

Build search visibility before launch, then turn live marketplace data into durable organic traffic after launch.

## Core audience groups

1. Guests searching for short stays in Jerusalem
2. Guests searching by neighbourhood, religious need, or trip type
3. Hosts deciding where to list a furnished stay
4. Returning users comparing areas, seasons, and stay features

## Search-intent clusters

| Cluster | Example intent | Best page type |
| --- | --- | --- |
| Neighbourhood demand | `apartments in Rechavia`, `stay in Ramat Eshkol` | Neighbourhood landing pages |
| Feature demand | `Jerusalem apartment with sukkah balcony` | Feature landing pages |
| Seasonal demand | `Pesach apartment Jerusalem`, `summer rental Jerusalem` | Seasonal pages |
| Comparison demand | `Rechavia vs German Colony` | Editorial guides |
| Host acquisition | `list my apartment in Jerusalem` | Host education pages |

## Priority page families

### 1. Neighbourhood pages

Create one strong page for each area that has real supply or real search interest:

- `/neighbourhoods/rechavia`
- `/neighbourhoods/ramat-eshkol`
- `/neighbourhoods/romema`
- `/neighbourhoods/german-colony`

Each page should include:

- A plain-English overview of the area
- Who it suits best
- Typical stay features there
- Nearby landmarks and practical notes
- Live listings from that area
- Internal links to adjacent neighbourhoods

### 2. Feature pages

Build pages around high-value filters:

- sukkah balcony
- kosher kitchen
- elevator
- parking
- near synagogues

These should only be published once there are enough matching listings to be useful.

### 3. Seasonal pages

Publish in advance of demand:

- Pesach stays in Jerusalem
- Sukkot stays in Jerusalem
- Summer stays in Jerusalem
- Yom Tov apartment rentals in Jerusalem

These should be refreshed yearly, not recreated from scratch.

### 4. Host growth pages

Pages for owners:

- How to list a furnished apartment in Jerusalem
- What makes a listing convert
- Photography checklist for Jerusalem stays
- How host payouts work on JLM Collective

## Data-led opportunities

Use live marketplace signals to decide what to publish next:

1. Top searched neighbourhoods
2. Listings with strong saves but few enquiries
3. Repeated searches that return too few results
4. Seasonal spikes in feature filters

When a neighbourhood repeatedly ranks highly in searches, it becomes a candidate for:

- a dedicated SEO page
- more host recruitment
- a homepage feature slot

## Internal linking model

- Home page links to strongest neighbourhood pages
- Neighbourhood pages link to live listings and related guides
- Feature pages link to matching neighbourhoods
- Host pages link back to listing quality guidance
- Every editorial page links to one practical conversion page

## Content quality rules

- No thin pages created only to capture keywords
- No neighbourhood page unless there is distinct local information
- No auto-generated copy published without human review
- Listings must remain the main value; articles support discovery
- Refresh old pages when supply, prices, or local advice change

## Structured data roadmap

Add or improve:

1. `Organization`
2. `WebSite`
3. `BreadcrumbList`
4. `LocalBusiness` only where appropriate
5. Listing-level schema once booking details are stable

## First 12 weeks

### Weeks 1-4

- Finish technical SEO baseline
- Publish 4 neighbourhood pages
- Publish 2 host education pages
- Connect analytics dashboard to search and engagement data

### Weeks 5-8

- Add 2 feature pages once supply exists
- Publish 2 comparison guides
- Improve internal links from homepage and stays pages

### Weeks 9-12

- Publish first seasonal page set
- Expand to 8-10 neighbourhood pages
- Use search-console queries plus on-site search data to choose next pages

## Practical KPIs

- Indexed public pages
- Search impressions by page family
- Click-through rate from search
- Top searched neighbourhoods
- Listing views to save rate
- Save to enquiry rate
- Enquiry to booking-request rate
